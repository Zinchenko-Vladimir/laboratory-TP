# Вариант 2 (базовый) — Калькулятор скидки
Запуск: `python -m http.server 8000` в папке проекта → http://localhost:8000

Модули: `pricing.js` (расчёт), `validators.js` (проверка), `main.js` (DOM и события).

## Тесты
| № | Ввод (цена / %) | Ожидаемо | Фактически |
|---|---|---|---|
| 1 | 1000 / 10 | Скидка 100, итого 900 | |
| 2 | 999.99 / 15 | Скидка 150, итого 849.99 | |
| 3 | пусто / 10 | «Введите цену» | |
| 4 | 500 / 150 | «Скидка должна быть от 0 до 100%» | |
| 5 | -50 / 10 | «Цена не может быть отрицательной» | |
