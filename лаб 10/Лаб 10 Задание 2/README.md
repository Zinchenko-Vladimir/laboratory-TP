# Вариант 9 (средний) — Корзина покупок
Запуск: `python -m http.server 8000` → http://localhost:8000

Модули: `products.js` (каталог), `cart.js` (логика), `ui.js` (DOM), `main.js` (события).

## Тесты
| № | Действие | Ожидаемо | Фактически |
|---|---|---|---|
| 1 | Добавить «Тетрадь» | В корзине 1 шт., итого 250 ₸ | |
| 2 | Добавить «Тетрадь» дважды | 2 шт., итого 500 ₸ | |
| 3 | Ввести количество 0 | «Количество должно быть целым числом не меньше 1» | |
| 4 | Ввести количество 2.5 | То же сообщение об ошибке | |
| 5 | Ввести количество 100 | «Максимум 99 штук одного товара» | |
| 6 | Нажать ✕ | Товар удалён, итого пересчитано | |
