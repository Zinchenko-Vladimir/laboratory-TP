# Вариант 19 (повышенный) — Доска Kanban
Запуск: `python -m http.server 8000` → http://localhost:8000

Модули: `tasks.js` (логика задач), `columns.js` (колонки и переходы), `storage.js` (localStorage), `ui.js` (DOM), `main.js` (события).

## Тесты
| № | Действие | Ожидаемо | Фактически |
|---|---|---|---|
| 1 | Добавить «Купить молоко» | Карточка в «К выполнению» | |
| 2 | Добавить пустое название | «Название задачи не может быть пустым» | |
| 3 | Добавить «ab» | «Название должно содержать минимум 3 символа» | |
| 4 | Добавить ту же задачу повторно | «Такая задача уже есть в этой колонке» | |
| 5 | Нажать → дважды | Карточка в «Готово», кнопка → неактивна | |
| 6 | Обновить страницу | Задачи сохранились | |
| 7 | Нажать ✕ | Карточка удалена | |
